User manual — Roadbook Generator

2026-11-14 · The screenshots show the French interface; the buttons have the same layout in English.

1. Getting started

The Roadbook Generator turns a GPX track (or a route drawn on the map) into a rally-raid roadbook: a list of three-box notes (distance, tulip, instructions), which can be exported as OpenRally GPX for the Roadbook Reader or printed as a PDF. The app version is shown at the bottom of the ⋯ menu.

Three clicks for a roadbook

  1. Open GPX (or Draw): load or draw the route.

  2. Generate roadbook: the app finds the junctions on the paths and computes tulips, distances and headings.

  3. Export GPX or Print: you get the roadbook.

After that you can correct a note (✎), add one by clicking on the track, or place waypoints (WPV, WPM, DZ…).

The main screen

  • Top: the roadbook name (editable) and the button bar.

  • Left: the map, with the place search, the choice of base map and layers, and the “Waypoint radii” checkbox.

  • Right: the roadbook, i.e. the description box followed by the notes, one per line. The column title shows the total distance and the number of notes.

Searching for a place

The “Place, address or coordinates” field at the top left of the map accepts a place name, an address or coordinates. In France it uses the IGN geocoder; elsewhere, Photon (OpenStreetMap). A marker appears for a few seconds on the place found.

Right click: Google Street View

A right click (or a long press on a touch screen) on the map or on the track opens a bubble “Open in Google Street View”. The link opens in a new tab on the nearest panorama. No note is added.

Theme

Language

  • The interface (menus, windows, buttons, tooltips) changes language.

  • The text of the automatic notes follows the same language: “Lég. à D / sur piste” becomes “Slight R / on track”, “Hors piste” becomes “Off piste”, “Début goudron” becomes “Tarmac starts”, “Rond-point, 2e sortie” becomes “Roundabout, 2nd exit”, and so on. The change applies immediately to the existing notes, without regenerating, in both directions. Notes edited by hand never change.

  • Not translated: proper names (streets, places), the free text you write, and the detailed reason behind “?”. The date field of the Altitude and timing window depends on the browser language.

2. Generate the roadbook

The ⚙️ Generate roadbook button downloads the paths around the track, snaps the track onto them, finds every junction and builds the notes with their tulips. Notes that were added, moved or edited by hand are never deleted by a new generation.

The “Generate roadbook” window

When you click, a window asks for two data sources, because they do not serve the same purpose:

  • Tulips: the source that draws the roads, tracks and junctions. In France, the IGN BD TOPO is the most faithful.

  • Instructions of the 3rd box: the source that provides road names, bridges, numbers and landmarks. Detailed OSM is the most complete.

You can use the same source for both. If they differ, the app loads a second network for the instructions only; if this second network is unavailable, it uses the tulip source and says so. A sentence under the lists announces what the description will say (“Tulips: … · Instructions: …”).

SourceCharacteristics
BD TOPO (IGN)Very faithful network, France only. Roads, paths, roundabouts, bridges, fords, road names and numbers, water, buildings
OpenFreeMap vector (OSM)Fast, worldwide, no key. Fewer landmarks
Detailed OSM (Overpass)The most complete (fences, STOP signs, sand, slopes…) but slower, and the free servers are sometimes overloaded

Careful with detailed OSM. When opened from a local file, the browser sends no web address and the Overpass servers often refuse the request. An orange box warns you in the window. In that case use the Web App hosted on GitHub, or choose the BD TOPO or OpenFreeMap. Overpass is also more patient than before (4 rounds over the 5 servers, with a waiting time that doubles), then falls back to OpenFreeMap and tells you.

During the computation

A progress bar shows the step (downloading the paths, snapping the track, finding the junctions, drawing the tulips) and the elapsed time. Cancel stops the generation.

The final report

When it is finished, a Roadbook generated — report window stays open until you click Close:

  • the number of notes, junctions, tight bends and landmarks;

  • the notes kept (edited by hand) and the notes recomputed;

  • the percentage of the route recognised on the paths;

  • the sources actually used;

  • a Good to know block with the warnings (source fallback, layers not loaded…) and the “Route poorly recognised” alert if less than 60 % of the track could be snapped.

The report stays open until you close it. 📋 Copy puts it in the clipboard, 💾 Save (.txt) saves it as a text file (roadbook name, date, version, result and warnings).

The report also lists the signs and obstacles that were found but left out, with the reason (for example: placed on a different way than yours, after the junction, wrong direction). You can reopen it at any time with ⋯ → 📋 Last generation report.

If the route is poorly recognised, increase Max gap track ↔ paths in the settings (for example 70 m), then regenerate.

Reading the result on the map

The black line on the map is the part of the track snapped onto the paths: the junctions are found on this line. Orange arrows show the direction of the track.

3. Notes and tulips

Each roadbook note fits on one line of three identical square boxes, as in an FIM / FIA roadbook. The roadbook starts with a large description box, then the notes in route order.

When you hover a note, three buttons appear: ? (why this note), ✎ (edit) and 🗑 (delete).

Reading a note

BoxContent
1st box (distance)Mileage at the top (with a comma), distance since the previous note in a frame at the bottom left, waypoint symbol on the right, note number in the black tab. A long arrow appears if the next note is 300 m away or less
2nd box (tulip)Drawing of the junction: dot = you arrive here, arrow = direction to take
3rd box (instructions)Direction, lexicon symbols, text, danger (red ! at the top left) and heading (CAP) in a frame at the bottom left: yellow = CAP active (exported and printed), grey = CAP disabled (visible on screen only). A click on the frame enables or disables it, a double click opens the heading measure. The frame always has the same size, whether the CAP has 1, 2 or 3 digits

Colours of the 1st box (FIM table): green background when the previous note is 300 m away or less; light blue for a WPM, yellow for a WPC, salmon for a WPS, pink for a WPN, orange for a DZ zone, bright green for a zone end FZ, grey for DN / FN / DT / FT.

Coloured frames: orange from the start to the end of a speed zone (DZ → FZ) or of a neutralisation with a speed limit; red for a WPS or a level-3 danger; pink around the tulip of a CP.

Reading a tulip

  • Pure blue = your route (thin line, blue arrow).

  • Black = the other paths, cut where the route passes.

  • Double line = tarmac road; solid line = track; dotted = trail or small track.

  • Sky blue = watercourse; grey rectangles = buildings.

  • The black continues before the starting dot and after the arrow: this is the road you come from and the one you go to (adjustable).

The automatic notes

The generation creates: Start and Finish, junctions (Straight, Slight L/R, Turn L/R, Hairpin, Keep L/R for forks), roundabouts (a single note, taken in the middle of the ring, with the exit number), tight bends outside junctions, off-piste sections, tarmac changes, and landmarks (fords, bridges, tunnels, level crossings, villages, churches, water towers, masts…). Grouping on the same road (FRO) or track (FPP) avoids writing one note per junction when the route does not leave the road.

The text of these notes is written in the app language (see “Language”, chapter 1). Known text lines are replaced by their FIA lexicon symbol (Bridge, Tunnel, Ford, roundabout, Straight → kpS, Keep Right → kpR…) and an ET symbol is inserted between symbols that combine.

Why this note?

In a note's window, the Why this note? box explains where it comes from: for example “3-way junction: turn left · IGN data”, or “8 junctions grouped: the track stays on the same road D 28”.

Drawing tab

  • Radius drawn in the tulip (m): larger = the tulip shows a wider area around the junction (from 20 to 150 m, specific to this note).

  • ✏️ Edit the tulip (lines, points): opens the tulip editor (chapter 4).

  • FIA lexicon symbols: two boxes side by side show the real rendering of the tulip and of the description box. You drag symbols into them; Size (slider or wheel), Rotation, Remove this symbol, Bring to front / Send to back adjust each symbol. ＋ Text adds a free text that can be moved, ＋ Add symbols opens the list (search in French or English, tabs by category: Tracks, On the track, Headings, Safety, Dunes / sand, Symbols, Controls, Abbreviations), 📥 Import my symbol adds a personal image.

Waypoint tab and Zone tab: see chapter 5.

Buttons: Delete (deletes the note), Cancel, Save.

Add, move, delete a note

  • Add: a click on the track places a note at that spot, analysed as during the generation (tulip, symbols, nearby landmarks). It carries the “manual” label on screen (not when printed) and survives a new generation. In an area of grouped junctions, the tulip is drawn at the clicked spot, not copied from the neighbouring note.

  • Move: a click on a note's number selects it; only the selected note can be moved. Drag it along the track (a bubble shows the gap and the new km), then a window asks you to confirm. Cancel puts the note back. The move is free: the note stays exactly where you drop it, and its content is regenerated for the new spot.

  • Delete: Delete button in the note's window.

The description box

The large box at the top of the roadbook holds a free text (rally, stage, date, start, instructions). It is saved automatically, printed at the top of page 1 (it counts for 2 places) and added to the description field of the exported GPX.

The blue line is the route: it moves like the others, but it remains the guiding thread of the tulip.

Check the notes (compare two sources)

⋯ › Check the notes compares, around each note (40 m), the ways known by two data sources. A note is flagged (⚠) when one of the sources shows at least 25 m of way that the other does not show. Nothing is modified by the check itself.

  1. Choose the Data source (the one of the current tulips) and the Base to compare. Possible choices: BD TOPO (IGN), IGN vector plan (BD TOPO), OpenFreeMap (OSM).

  2. Click Run the check: the app downloads the second source if needed and lists the notes to re-check, with the number of metres of way in disagreement.

  3. Touch a line: the window shows the two tulips side by side (A and B), and the map behind stays usable (zoom, pan) so you can judge on the ground.

  4. Click Keep A or Keep B: the chosen tulip replaces the note's one, which is then marked as edited. The ‹ › arrows go to the next or previous flagged note, ← List goes back to the list.

  5. Clear the ⚠ removes the warning marks without changing the notes.

Advanced use: by choosing the best tulip note by note, you get a roadbook built from two sources. The description then says “tulips chosen with … (n notes)”.

5. Waypoints, zones, dangers and analysis tools

Waypoints (Waypoint tab of a note)

A waypoint turns a note into a regulation checkpoint: the official FIM lexicon symbol appears in the 1st box, circles are drawn on the map and the exported GPX declares it to the reader. One main waypoint per note; it can be combined with a speed zone and fuel.

The fields of the tab:

  • Name / no.: “auto” by default, or a name of your own (WP 12, CP 3…).

  • Opening (m): distance at which the waypoint becomes active. Empty = always visible or never opened, depending on the type.

  • Validation (m): distance at which it is validated. The values of the FIM table are proposed and can be edited according to the event's regulations.

  • Time limit (min, optional): for a DSS or a DT. Exports the time-control tag (timecontrol allowed) in the GPX, so that the reader can compute a time limit. Reading this limit and the overrun penalty are still being developed on the reader side.

  • Max speed (km/h, optional): for a DN or a DT with a speed limit (orange symbol).

  • Neutralisation duration (min): for a DN. Exported in seconds in the GPX.

The circles are shown on the map when the ◎ Waypoint radii checkbox is ticked: dotted blue circle = opening, purple circle = validation. The selected note has thicker lines. The radii of a DN can be adjusted like those of the other waypoints and are exported in the GPX. The state of the checkbox is remembered in the browser.

Speed zones (Zone tab)

  • DZ — zone start: start of a speed-limited zone. The Max speed (km/h) field gives the number on the orange sign.

  • FZ — zone end: end of the current zone; the sign is crossed out.

  • FZ + DZ: end of one zone and start of the next on the same note.

Effect: all the notes between DZ and FZ get an orange frame, the 1st box changes colour (orange for DZ, bright green for FZ), and the GPX carries the dz / fz tags with their speed. Fixed radii of 1000 m / 90 m.

Dangers

The Danger field of the Note tab adds 1, 2 or 3 red exclamation marks at the top left of the 3rd box. Level 3 (like a WPS) draws a red frame on the line. The reader picks them up from the GPX.

During generation, the app also adds danger notes found on the map (pedestrian crossing, traffic lights, speed bump, rumble strips, etc.) with their symbols, and flags the entry and exit of a village. Each type can be switched off or on again in the settings (“Which notes to create”).

Measure a heading / list of turns

⋯ › Measure a heading / list of turns opens a measuring panel on the map. Headings are measured from north (0° = north, 90° = east, 180° = south, 270° = west). The panel can be moved: drag its title to put it wherever you want on the map.

  • Single measure: click on the track near a bend; the panel gives the arrival heading and the exit heading.

  • In (15, 30, 50 m) and Out (15 to 200 m): length of track used before and after the bend to compute these headings.

  • Turns ≥ (20 to 90°): minimum angle for a turn to be listed.

  • Only turns without a note: limits the list to turns that do not have a note yet.

  • The list: one line per turn with the km, the headings arrival → exit, the angle and the direction (↱ right, ↰ left), and an indicator ○ (no note) or ● n (note n exists). It lets you place a note with its CAP where one is missing.

Stages

⋯ › Stages splits the route: distance and elevation per stage, padlock 🔒 to lock a stage (no change is possible in it), GPX button to export a single stage, Add a cut to create a new stage and Compute elevation (internet required).

Altitude and timing

⋯ › Altitude and timing: Compute altitude gives the profile and the 3D view. Timestamping estimates the times: start time, average speed (with or without taking the slope into account), duration and finish per stage. The Add the times (and altitude) to the exported GPX track checkbox writes them into the track.

Markers

⋯ › Markers places useful landmarks on the map: shelters, water, fuel. Shelters, water, fuel (visible area) searches for them in the displayed area; Add on the map places a marker by hand (icons: Shelter, Water, Fuel, Meal, Bivouac, Danger, Photo, Parking, Viewpoint, Landmark). The Add them to the exported GPX checkbox includes them in the file.

Base map intensity: a 0 to 100 % slider fades the base map so the track and the notes stand out.

Heatmap and layers

The Heatmap / layers menu overlays information useful on the ground. A second slider adjusts their intensity.

  • GPS traces (OpenStreetMap): where people actually ride.

  • Marked hiking trails, Marked MTB routes, Marked cycling routes.

  • LiDAR HD: relief without the trees. Relief shading: hillshade (blurry when zoomed in close).

  • Steep slopes (≥ 30°): useful in the mountains.

  • Public forests (ONF), Forest rescue points (PRSF), Forest accessibility: carrying and skidding.

Waypoint radii

The ◎ Waypoint radii checkbox shows on the map the opening circles (blue, dotted) and validation circles (purple) of each waypoint (see chapter 5).

Draw mode

✏️ Draw places points on the map: the route follows the paths. If a track is already loaded, the app asks whether you want to edit it (the notes are kept and must be regenerated) or erase it to draw a new one (the notes are then deleted).

Placing points: a click places a point, drag a point to move it, a click on it removes it, and pull on the track to add a point to it.

🧲 Routing: on / off (R key): at any time, you choose whether the next points follow the paths (green) or are joined by a straight line to go off piste (white). Each section keeps the setting it was placed with: changing the button does not modify what is already drawn. The 🧲 menu next to it sets the magnet distance (5, 10, 20, 30, 40 or 50 m) or turns it off (Magnet off: routing stays active, but points are placed exactly where you click).

Magnet: when routing is on, a placed or moved point snaps to the nearest road or path. If it is farther than the set distance (40 m by default), it is not placed and a message tells you: bring it closer, or turn routing off. If the path is unknown to the route calculator but is on the map (OpenStreetMap), the route still follows it: it follows the road to the junction, then the path. If the junction is not found, the section stays a straight line (message on screen). Moving a point recomputes the sections that touch it.

Drawing

  • ↶ Undo / ↷ Redo (Ctrl+Z / Ctrl+Y).

  • ✍ Freehand: hold the space bar (or the button) and draw freely.

  • 🧽 Eraser: erases points by hovering over them with the button pressed.

  • ✔ Finish: leaves draw mode.

Editing the track

  • ✂ Cut: a click on the track deletes the beginning or the end, or changes the start point of a loop.

  • ⇅ Reverse: reverses the direction of the route.

  • ➕ Merge a GPX: adds another GPX file after or before.

  • 👆 Select: picks a point (1 click) or a section (click the 1st then the last point); “Snap to road” will only process the selection.

  • Reduce points: decreases the number of points of the track.

  • 🛣 Snap to road: recomputes the selection (a point or a section chosen with 👆) so that it follows the paths, according to the chosen route type. The button stays greyed out while nothing is selected.

A locked stage (padlock in Stages) cannot be modified.

Path memory

The downloaded paths are kept in the browser to go faster. The Clear this memory button (bottom of the window) erases them. ⋯ › Save the OSM paths makes a copy in a folder of your choice (.rbosm file) and ⋯ › Load OSM paths reloads them: the generation no longer needs to download them.

8. Saving, export, printing and installation

Saving your work

  • Automatic save: your work is kept automatically in the browser (track, notes, settings, description). You find your roadbook again when you reopen the app.

  • 🗂️ Save (or ⋯ › Save the project): creates a .json project file to keep or to pass on. The orange dot on the button means unsaved changes.

  • Reopen: 📂 Open GPX also accepts the .json file.

  • 🆕 New roadbook (⋯ menu): starts from scratch (track, notes, description and saved sources are erased).

  • ↩️ Cancel / Ctrl+Z: undoes the latest changes.

The file is an OpenRally GPX v1.0.3: tulips and notes as images, distance, heading, danger, waypoints with their opening and validation radii, DZ / FZ zones with speed, fuel, DN neutralisations (duration), time limit, roadbook description and the snapped track. A GPX exported without the project, reopened in the editor, only gives the track. The Track and Orienteering modes only keep the points that carry a waypoint, a zone or fuel, with no tulip image and no note: try them in your reader first.

Printing

🖨️ Print opens the browser print dialog, which also lets you save as PDF. The layout follows the on-screen roadbook: strip of 3 boxes of 48 mm, 5 notes per A4 page, a header on each page (name, page number, total in km). The description takes 2 places at the top of page 1. The “manual” label is never printed. Disabled (grey) CAPs are not printed.

Web App and local file

When you open the HTML file directly (without a web address), the detailed OSM option (Overpass) is often refused. The generation window then shows a warning with the link 🌐 Open the Web App: save your project (🗂️), open the Web App, then reopen the project.

  • Web App (GitHub Pages): the app is installed like an application (computer or phone), works with a real web address and updates itself. If the old version still shows, closing and reopening the app loads the new one.

  • Local HTML file: convenient, but the browser does not send a web address to the servers. Detailed OSM (Overpass) is often refused there; the IGN BD TOPO and OpenFreeMap work normally.

  • An internet connection is needed for the map, the route calculation and the download of the paths (except paths already in memory).
